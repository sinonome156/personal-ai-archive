# AI-READONLY: 归档区（历史项目 / 旧文档 / 已完成任务）

> 归档 ≠ 删除。归档是"完结但仍可能被未来的 AI 引用"的内容。活跃内容一律不放这里，本目录内容默认**只读**。

## 目录结构

```
archive/
├── projects/      # 已完结项目：一个项目一个子目录或一个文件
│   └── README.md  # 项目归档索引
├── documents/     # 旧版本文档、被取代的规范
└── tasks/         # 已完成的一次性任务记录
```

## 归档规则（AI 执行移入操作前必读）

1. **移入时机**：项目验收/任务完结/文档被新版取代时；或每季度档案大扫除时统一处理。
2. **移入动作**：
   - 新建 `archive/projects/YYYY-项目名.md`（或整目录移动），文件头部写"归档卡"（见模板）。
   - 原位置内容删除或替换为一行指向归档路径的链接。
   - 更新本目录对应 `README.md` 索引 + `identity/02-current-context.md` 移除该进行中条目。
   - 按 `AGENTS.md` 提交规范单独提交：`archive(projects): 归档XX项目`。
3. **AI 读取约定**：回答"我以前做过什么/当时怎么做的"时可检索本目录；但**不要把归档内容当作现行有效**，除非用户明确回溯。

## 归档卡模板

```markdown
# AI-ARCHIVED: {{项目/文档名}}（归档于 YYYY-MM-DD）

- 活跃期：YYYY-MM ~ YYYY-MM
- 一句话结论：{{做成了什么/为什么完结}}
- 关键产出清单：{{文件名+路径+一句话说明}}
- 沉淀去向：经验 → `memory/lessons.md`；决策 → `memory/decisions/`；技能 → `skills/`
- 复用价值：{{什么场景下未来 AI 可以再参考这份归档}}
```
