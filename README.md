# Personal AI Archive — 跨AI通用个人记忆系统

> 一次搭建、全平台复用。这是你的"数字化自传"，任何 AI（ChatGPT / Claude / Gemini / Meta Muse / OpenAI dots / 本地编码 Agent）都可以读取它来理解你是谁、你怎么工作、你偏好什么。

## 这个仓库是什么

- **AI 可读的个人档案**：全部内容为纯 Markdown，无需任何格式转换，AI 直接读取、直接修改。
- **跨设备同步**：GitHub 是唯一真源（single source of truth），换电脑、换 AI 平台，档案跟人走。
- **持续生长**：AI 完成任务后按协议把新经验、新偏好写回对应目录（见 `AGENTS.md`）。
- **可回退**：每一次修改都是一条 git 提交，任何时间点都能一键恢复。

## 目录结构

| 目录 | 内容 | 更新频率 |
|---|---|---|
| `identity/` | 身份、职业、核心标签、人生目标、当前上下文 | 低频（季度） |
| `workflow/` | 工作习惯、常用工具、沟通风格、任务优先级规则 | 中频（月度） |
| `memory/` | 重要决策记录、历史经验、AI 对话沉淀的偏好 | 高频（每次任务后） |
| `skills/` | 已掌握技能、学习计划、待提升能力清单 | 中频 |
| `archive/` | 历史项目、旧文档、已完成任务归档 | 低频 |

核心文件：
- **`AGENTS.md`** — AI 读写协议（最重要：定义 AI 何时读、写回哪、怎么提交）
- **`ai-integration.md`** — 各 AI 平台的接入方法速查

## 快速开始（3 步）

1. **填占位符**：全仓库搜索 `{{`，把模板中的占位符替换为你的真实信息（可以直接让 AI 访谈你后代填）。
2. **接入你的 AI**：按 `ai-integration.md` 中对应平台的说明操作（复制仓库地址即可开始）。
3. **建立回写习惯**：对 AI 说一句固定指令（见 `ai-integration.md` 末尾），让每次重要任务的经验自动沉淀进 `memory/`。

## 版本保护与一键回退

- 所有修改自动生成提交记录（提交信息规范见 `AGENTS.md`）。
- `main` 分支已开启保护：禁止 force push、禁止删除分支，AI 误改可整体回退。
- 回退操作（任选其一）：
  - GitHub 网页：仓库 → Commits → 找到正确版本 → `...` → Browse repository at this point
  - 命令行恢复单个文件：`git checkout <commit-id> -- identity/00-profile.md`
  - 整体回退（生成一次"撤销提交"，不改历史，最安全）：`git revert <commit-id>`
  - 查看任意文件的完整演变：GitHub 上打开文件 → `Blame` / History

## 安全红线（对人也对 AI 有效）

- ❌ 本仓库为**公开仓库**：严禁写入密码、API Key、身份证号、银行卡号、家庭住址等机密信息。
- ✅ 可以写：职业信息、偏好、决策思路、经验教训、公开的项目成果。
- ⚠️ 若某天需要存放敏感版本，克隆一份设为 private 仓库，或从本仓库中删除对应内容并**彻底清洗历史**（见 GitHub 官方 BFG 工具文档）。
