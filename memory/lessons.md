
## 数据与口径类

- [2026-10] 定稿前用独立脚本从原始数据重取数、逐条断言关键数字，0 项不符才交付；校验条数写进交付说明。
  触发场景：任何含关键数字的交付物定稿前。
  代价/收益：未经验证的数字被审计一次击穿的信用损失，远大于校验的时间成本。

## 交付与沟通类

- [2026-10] 绝对化措辞（唯一/全是/连续N月/最优）必须由数据算出并正则全文扫描，核对因果方向。
  触发场景：汇报稿/PPT 定稿前。
  代价/收益：一处绝对断言与数据不符，会连带质疑全篇。

## 工具与环境类

- [2026-10] Windows PowerShell 5.1 按 GBK 读取无 BOM 的 .ps1，含中文的脚本必须先加 UTF-8 BOM，否则乱码找不到文件。
  触发场景：本机编写/运行含中文的 PowerShell 脚本。
  代价/收益：一次乱码排障的返工时间。
- [2026-10] 含中文的 file:// URL 需百分号编码，否则浏览器报多目标错误；无头截图窗口高度超约 8200px 会静默不出图，需分段截取。
  触发场景：本机用浏览器引擎做页面渲染截图。
  代价/收益：静默失败无报错，只能靠分段规避。

- [2026-10-23] GitHub 设备码一次性码约 15 分钟过期；隔了很久才完成授权大概率白跑，须清残留进程重发新码，且授权不要求同设备（手机可用）。
  触发场景：任何 gh CLI 设备码登录流程。
  代价/收益：一次"以为成功了"的无效等待。
- [2026-10-23] 本机网络到 github.com:443 间歇断连（同期 api.github.com 稳定），推送失败先用短连接超时+固定间隔重试循环，首窗即过；核验一律走 API（refs 端点）而非再次 git 网络调用。
  触发场景：本机 git push/pull 报 "Could not connect"。
  代价/收益：避免误判"永久被墙"去走 UAC/代理等重方案。
